# Тап-Империя

Большая мобильная игра-кликер (idle/incremental) на чистом HTML + CSS + JavaScript.
Без внешних библиотек, устанавливается на телефон как PWA и работает офлайн.

## Запуск

Любой статический веб-сервер из корня репозитория, например:

```
npx http-server -p 8080
```

и открыть `http://localhost:8080`.

## Структура

- `index.html` — разметка, `style.css` — стили (тёмная неоновая тема);
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA и офлайн-режим;
- `js/util.js` — форматирование чисел (K, M, B, T, aa, ab…), морфинг DOM;
- `js/core.js` — ядро: модули, события, валюты, характеристики, цикл, сохранение;
- `js/ui.js` — вкладки, панели, модальные окна, уведомления;
- `js/tap.js`, `js/buildings.js`, … — отдельный модуль на каждую систему.
