# PC Simulator 2

Симулятор сборки компьютеров от первого лица. Написан на **чистом C++17 и OpenGL**, без сторонних библиотек. На Windows используются только системные WinAPI и OpenGL, на Linux — X11 и GLX. Шрифт с кириллицей встроен прямо в exe.

## Что есть в игре

- **Комната от первого лица:** стол с монитором, верстак, стеллаж, зона доставки у двери и поддон для отправки и продажи.
- **Телефон-магазин** (Tab). Покупки приезжают в коробках, коробку распаковывают клавишей E.
- **Реальная сборка:** деталь берёте в руки и вставляете в слот. Перед установкой показывается полупрозрачный «призрак» детали: зелёный — подходит, красный — не подходит, с объяснением причины.
  - сокет процессора должен совпадать с платой (LGA1155, LGA1200, LGA1700, AM4, AM5);
  - тип памяти должен совпадать с платой (DDR3, DDR4, DDR5);
  - NVMe ставится в слот M.2 на плате, HDD и SATA SSD — в отсеки корпуса;
  - кулер нельзя поставить без процессора, процессор нельзя вынуть, пока стоит кулер.
- **Видеокарты ниже 40-й серии помечены NOT SUPPORTED.** Изображения с ними нет: ПК работает, только если у процессора есть встроенная графика.
- **Термопаста:** без неё процессор перегревается. При снятии кулера паста стирается, и её нужно наносить заново.
- **BIOS** (DEL при загрузке). У каждого бренда своё оформление:
  - **Raven** — чёрно-красный, меню слева;
  - **Polaris** — тёмно-синий, вкладки сверху и колонка с описанием;
  - **NovaBIOS** — классический сине-серый, для плат без бренда.

  Разделы BIOS: сведения о системе, разгон процессора (частота, Vcore, авто-разгон), качество кристалла, XMP/EXPO, мониторинг (температуры, напряжения, обороты), профили вентиляторов, порядок загрузки, сохранение и выход.
- **NovaOS:** установка с флешки и рабочий стол с программами:
  - BenchMax — тест с таблицей лидеров;
  - Сенсоры — графики температур;
  - OC Tuner — разгон видеокарты;
  - NovaMiner — майнинг;
  - RGB Studio;
  - Магазин;
  - Змейка — +$1 за яблоко;
  - О системе.
- **Физика компьютера:** температуры зависят от кулера, термопасты и вентиляторов, потребление сравнивается с мощностью блока питания. Если БП слабый, ПК выключается под нагрузкой. Высокое напряжение при перегреве сжигает процессор.
- **«Кремниевая лотерея»:** каждый процессор и каждая видеокарта разгоняются по-разному.
- **Заказы клиентов:** соберите ПК под требования, поставьте его на поддон и получите награду.
- **Продажа** ненужных деталей через поддон.
- Сохранение, автосохранение раз в минуту и настройки.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, Shift, C/Ctrl, Пробел | ходьба, бег, присесть, прыжок |
| ЛКМ | взять / поставить / установить в слот / вынуть деталь |
| ПКМ | повернуть предмет в руках |
| G | бросить предмет |
| E | распаковать коробку, кнопка питания ПК, сесть за монитор |
| DEL | войти в BIOS во время загрузки |
| Tab | телефон |
| Esc | пауза / встать из-за компьютера |
| F11 | полный экран |

## Как получить exe

**Готовая сборка.** На каждый push GitHub Actions собирает `PCSimulator2.exe`. Откройте вкладку **Actions**, выберите последний запуск **Build** и скачайте артефакт **PCSimulator2-Windows**.

**Visual Studio + CMake:**
```
cmake -S . -B build -A x64
cmake --build build --config Release
```
Exe появится в `build/Release/PCSimulator2.exe`.

**Без CMake.** Запустите `build.bat` из «Developer Command Prompt for Visual Studio».

**MinGW:**
```
g++ -std=c++17 -O2 -mwindows src/*.cpp -o PCSimulator2.exe -lopengl32 -lgdi32 -luser32 -lwinmm -static
```

**Linux.** Нужны заголовки X11 и GL (`libx11-dev`, `libgl-dev`):
```
cmake -S . -B build && cmake --build build -j
./build/PCSimulator2 --selftest   # проверка игровой логики без окна
```

## Устройство кода

| Файл | Что внутри |
|---|---|
| `src/platform_*.cpp` | окно, ввод, время, звук (WinAPI/WGL и X11/GLX) |
| `src/render.cpp` | OpenGL 1.1: пакеты вершин, освещение граней, 2D-холсты (в том числе на экране монитора в 3D), текст |
| `src/font_data.hpp` | встроенный атлас шрифта DejaVu Sans; генерируется `tools/make_font.py` |
| `src/parts.cpp` | каталог комплектующих и цены |
| `src/world.cpp` | комната, предметы, слоты установки, физика, низкополигональные модели |
| `src/computer.cpp` | симуляция ПК: POST, BIOS, загрузка, температуры, питание, разгон, майнинг |
| `src/game.cpp` | игрок, взаимодействие, заказы, продажа, сохранения |
| `src/game_ui.cpp` | HUD, телефон, меню, настройки |
| `src/os.cpp` | экран компьютера: POST, BIOS трёх видов, установщик, NovaOS |
| `src/selftest.cpp` | самопроверка логики (`--selftest`) |

Шрифт DejaVu Sans распространяется по свободной лицензии (`assets/fonts/LICENSE-DejaVu.txt`).
