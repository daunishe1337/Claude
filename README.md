# Тап-Империя

Большая мобильная игра-кликер (idle/incremental) на чистом HTML + CSS + JavaScript.
Внешних библиотек нет. Игра ставится на телефон как PWA и работает офлайн.

## Как установить игру на телефон

Чтобы браузер предложил установку PWA, игру нужно открыть по **HTTPS**. Проще всего через GitHub Pages:

1. В репозитории на GitHub откройте **Settings → Pages**.
2. В поле **Source** выберите ветку с игрой и папку `/ (root)`, нажмите **Save**.
3. Через минуту появится адрес вида `https://<логин>.github.io/<репозиторий>/`.
4. Откройте этот адрес на телефоне:
   - **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на главный экран».
   - **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».
5. Игра появится на рабочем столе с иконкой. Она запускается во весь экран в вертикальной ориентации и после первого запуска работает без интернета.

Подойдёт и любой другой хостинг статических файлов с HTTPS, например Netlify или Cloudflare Pages. Достаточно загрузить в него папку проекта целиком.

Прогресс хранится в браузере телефона (localStorage). Перед сменой телефона или очисткой данных браузера сделайте резервную копию: **Ещё → Настройки → Экспорт**. Получится строка, которую потом можно вставить через «Импорт».

## Запуск на компьютере

```
npx http-server -p 8080
```

Затем откройте `http://localhost:8080`. Можно открыть и просто `index.html` двойным щелчком: игра заработает, но без офлайн-режима, потому что service worker не работает с адресами `file://`.

## Что есть в игре

**Основное:** большой объект для тапа в центре экрана, мультитач (каждый палец считается отдельным тапом), всплывающие «+N», сжатие объекта, частицы, вибрация, звуки (генерируются через WebAudio, без файлов). Числа записываются как 1.5K, 2.3M, 4.1B, 7.8T, дальше aa, ab, ac…

Системы открываются по мере прогресса. Подсказка на закрытой плитке объясняет, что нужно сделать, чтобы её открыть.

**Баланс** настроен по симуляциям, в которых бот тапает и покупает оптимально. Новая покупка в начале появляется каждые несколько секунд, а после 10-й минуты примерно раз в 10–30 секунд. Первое улучшение стоит 10 тапов. Первый престиж у живого игрока наступает примерно через 30–60 минут, вознесение — через несколько дней (от 1000 кристаллов), перерождение вселенной — через недели. На экране тапа всегда видны ближняя цель (следующая покупка) и дальняя (босс или престиж).

## Структура

- `index.html` — разметка, `style.css` — стили (тёмная неоновая тема, экраны 360–430 px).
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA и офлайн-режим.
- `js/util.js` — форматирование чисел и времени, ГПСЧ, «морфинг» DOM.
- `js/core.js` — ядро: реестр модулей, шина событий, валюты, характеристики, цены, цикл, сохранение, сбросы.
- `js/ui.js` — вкладки, панели, модальные окна, уведомления, красные точки.
- `js/audio.js`, `js/fx.js` — звуки и визуальные эффекты.
- По модулю на каждую систему: `tap.js`, `buildings.js`, `crit.js`, `combo.js`, `autotap.js`, `boosters.js`, `skills.js`, `events.js`, `stage.js`, `offline.js`, `achievements.js`, `prestige.js`, `hero.js`, `gear.js`, `pets.js`, `artifacts.js`, `mine.js`, `forge.js`, `farm.js`, `alchemy.js`, `bank.js`, `exchange.js`, `city.js`, `army.js`, `research.js`, `stars.js`, `dungeon.js`, `tower.js`, `cards.js`, `cosmetics.js`, `weather.js`, `wheel.js`, `quests.js`, `daily.js`, `season.js`, `liveevent.js`, `shop.js`, `meta.js`, `settings.js`; запуск — `main.js`.

Каждый модуль регистрируется через `G.mod({...})`. В нём описаны состояние, уровень престижа для сброса, вклад в характеристики (`stats`), обработчик цикла (`tick`), офлайн-обработчик, панели и действия. Кнопки вызывают действия через атрибут `data-a="модуль.действие:аргумент"`. Автосохранение срабатывает каждые 5 секунд и при сворачивании игры.
