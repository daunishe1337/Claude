# HackTerm — хакерский терминал с живой компиляцией C++

Консольное приложение для Windows в стиле «хакерского» терминала: чёрный фон,
зелёный моноширинный текст, мигающий курсор, эффект печати, Matrix-дождь при
запуске. Пишете C++ прямо в нём, жмёте **F5** или **Ctrl+Enter**, и код
компилируется, запускается, а вывод в реальном времени появляется в нижней панели.
Ввод с клавиатуры уходит в stdin запущенной программы.

```
 ▓▒░ HACKTERM ░▒▓  untitled.cpp [+]                       g++ 13.2.0 │ C++17 │ Ln 7, Col 5
    1 │ // HackTerm :: payload.cpp
    2 │ #include <iostream>
    3 │
    4 │ int main() {
 ►  5 │     std::cout << "Hello, World!" << std::endl
    6 │     return 0;
    7 │ }
──[ OUTPUT ]──[ IDLE ]───────────────────────────────────[ F5 run · Esc cmd · F1 help ]──
 [*] Compiling main.cpp :: g++ 13.2.0 -std=c++17 ...
 main.cpp:5:46: error: expected ';' before 'return'
 [-] BUILD FAILED: 1 error(s), 0 warning(s), exit code 1
 [>] Курсор на строке 5 (F8 — следующая ошибка)
root@hack:~# [Esc] командная строка · [F5] запуск · [F1] помощь
```

## Почему консоль Windows + VT, а не собственное окно WinAPI

Я выбрал **консоль Windows с `ENABLE_VIRTUAL_TERMINAL_PROCESSING`**:

1. **Это настоящий терминал.** Программа запускается в cmd, PowerShell или
   Windows Terminal и выглядит как родной инструмент. Шрифт, масштаб,
   прозрачность и полноэкранный режим даёт сама консоль.
2. **Truecolor и позиционирование бесплатно.** VT-последовательности
   (`ESC[38;2;r;g;bm`, `ESC[row;colH`, альтернативный экранный буфер `?1049h`)
   поддерживаются в Windows 10 1607+ и Windows Terminal. Подсветка синтаксиса
   получается в любых оттенках, без GDI.
3. **Без мерцания.** Кадр собирается в одну строку и выводится одним вызовом
   `WriteConsoleW`, стиль переключается только при его смене.
4. **Полный контроль над клавиатурой.** `ReadConsoleInputW` с выключенным
   `ENABLE_PROCESSED_INPUT` отдаёт сырые события: F5, Ctrl+Enter, стрелки,
   колесо мыши и Ctrl+C как обычную клавишу, а не сигнал завершения.
5. **Меньше кода и рисков.** Собственное окно потребовало бы своего рендера
   текста, обработки IME, DPI, выделения, буфера обмена и прокрутки, то есть
   в несколько раз больше кода без выигрыша для задачи.

Альтернативный экранный буфер не портит историю консоли: после выхода всё
выглядит как до запуска.

## Структура проекта

| Файл | Назначение |
|---|---|
| `src/main.cpp` | Точка входа |
| `src/App.h/.cpp` | **App**: главный цикл, горячие клавиши, команды, конвейер «сохранить → компилировать → запустить», сессия |
| `src/Editor.h/.cpp` | **Editor**: многострочный редактор, курсор, автоотступ, undo/redo, маркеры ошибок |
| `src/Syntax.h/.cpp` | Лексер для подсветки синтаксиса C++ (ключевые слова, типы, строки, числа, комментарии, препроцессор) |
| `src/Compiler.h/.cpp` | **Compiler**: поиск g++ → MSVC cl → clang++, командная строка сборки, разбор ошибок |
| `src/Runner.h/.cpp` | **Runner**: `CreateProcess` с пайпами stdin/stdout/stderr, фоновые потоки чтения, Job Object, kill, таймаут |
| `src/UI.h/.cpp` | **UI**: отрисовка редактора, панели вывода, статуса и командной строки; заставка и Matrix-дождь |
| `src/Theme.h/.cpp` | **Theme**: цветовые темы (matrix, amber, ice) и генерация VT-последовательностей |
| `src/Console.h/.cpp` | Низкоуровневая работа с консолью: режимы, альтернативный буфер, чтение событий ввода |
| `src/OutputPane.h/.cpp` | Буфер вывода с эффектом печатной машинки, переносом строк, обработкой `\r` и вырезанием ANSI |
| `src/Common.h/.cpp` | Утилиты: UTF-8 ↔ UTF-16, потоковый декодер, файлы, RAII-обёртка `HANDLE` |
| `tests/selftest.cpp`, `tests/child.cpp` | Самопроверка не-UI частей (процессы, пайпы, парсер ошибок, редактор) |
| `build.bat`, `CMakeLists.txt` | Сборка |

Используются только стандартная библиотека C++17 и WinAPI.

## Сборка в .exe

### Visual Studio (cl)

Откройте **Developer Command Prompt for VS** (или x64 Native Tools Command Prompt) в папке проекта:

```bat
cl /nologo /std:c++17 /EHsc /O2 /W4 /utf-8 /DUNICODE /D_UNICODE src\*.cpp /Fe:hackterm.exe /link user32.lib
```

`/utf-8` обязателен: исходники в UTF-8 и содержат кириллицу и псевдографику.

### MinGW-w64 (g++)

```bat
g++ -std=c++17 -O2 -Wall -Wextra -static -o hackterm.exe src\*.cpp
```

`-static` делает exe независимым от `libstdc++-6.dll`, его можно копировать куда угодно.

### Скрипт и CMake

```bat
build.bat          :: сам выберет cl или g++
build.bat gcc
build.bat msvc

cmake -B build && cmake --build build --config Release
```

## Использование

Запустите `hackterm.exe` в cmd, PowerShell или (лучше всего) в **Windows
Terminal**. После заставки откроется редактор. При первом запуске в нём
шаблон Hello World, дальше код восстанавливается из прошлой сессии
(`%LOCALAPPDATA%\HackTerm\session.cpp`).

Экран делится на три зоны: **редактор** сверху, **панель вывода** внизу и
**командная строка** `root@hack:~#` в последней строке.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| **F5**, **Ctrl+Enter**, Ctrl+R | Скомпилировать и запустить |
| **Ctrl+C** | Остановить компиляцию или программу |
| **Esc**, F2 | Переключить фокус: редактор → командная строка → stdin программы |
| F1 | Справка |
| F8 | Перейти к следующей ошибке компиляции |
| Ctrl+S / Ctrl+O | Сохранить / открыть файл |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+D / Ctrl+K | Дублировать / удалить строку |
| Ctrl+V | Вставить из буфера обмена |
| Tab / Shift+Tab | Отступ 4 пробела / уменьшить отступ |
| Home | Умный Home: к первому непробельному символу, повторно — в начало строки |
| Ctrl+←/→, Ctrl+Home/End | По словам / в начало и конец файла |
| Ctrl+↑/↓, Shift+PgUp/PgDn, колесо мыши | Прокрутка вывода (колесо над редактором прокручивает код) |
| Ctrl+L | Очистить вывод |
| Ctrl+Z или Ctrl+D в режиме stdin | Отправить программе EOF |
| Ctrl+Q | Выход |

### Команды

Нажмите **Esc** и введите команду (префикс `:` или `/` необязателен).
Tab дополняет имя команды, ↑/↓ листают историю.

| Команда | Действие |
|---|---|
| `:run` | Компиляция и запуск |
| `:new` | Очистить редактор (можно отменить через Ctrl+Z) |
| `:save <имя>` | Сохранить код; без расширения добавится `.cpp`. Без аргумента — в текущий файл |
| `:load <имя>` | Загрузить код (UTF-8 или ANSI/cp1251) |
| `:files` | Список `*.cpp` в текущей папке |
| `:clear` | Очистить вывод |
| `:goto <N>` | Перейти к строке N |
| `:stop` | Убить запущенный процесс |
| `:timeout <сек>` | Лимит времени выполнения (по умолчанию 10, `0` — без лимита) |
| `:compiler [gcc\|msvc\|clang]` | Список найденных компиляторов или выбор |
| `:std <17\|20\|23>` | Стандарт языка |
| `:theme <matrix\|amber\|ice>` | Цветовая тема |
| `:matrix` | Пасхалка |
| `:about` | О программе |
| `:help` | Список команд |
| `:exit` | Выход |

### Работа с программой во время выполнения

Когда программа запущена, фокус переходит в строку `stdin>`. Набранная строка
по Enter уходит в stdin программы и отображается в выводе. Пока программа
работает, в статусе тикает таймер `RUNNING 1.25s / 10s`. По таймауту или
Ctrl+C завершается всё дерево процессов.

## Как это устроено

* **Поиск компилятора** (`Compiler::detect`). Порядок: `g++.exe` в PATH, затем в
  типичных каталогах (`C:\msys64\ucrt64\bin`, `C:\mingw64\bin`,
  `C:\TDM-GCC-64\bin`…); `cl.exe` в PATH, затем Visual Studio через
  `vswhere.exe` (cl запускается через `vcvars64.bat`, поэтому Developer
  Prompt не нужен); `clang++.exe`. Если ничего не найдено, выводится
  инструкция по установке.
* **Сборка.** Код пишется во временную папку `%TEMP%\HackTerm\run_<pid>\main.cpp`
  (UTF-8). Рядом кладётся вспомогательный `hackterm_rt.cpp`: статический объект
  отключает буферизацию `stdout` (`setvbuf(_IONBF)` + `std::unitbuf`). Без него
  CRT при выводе в пайп буферизует вывод, и он появлялся бы только после
  завершения программы.
* **Процессы** (`Runner`). `CreatePipe` для stdin/stdout/stderr, наши концы
  помечаются как ненаследуемые. `CreateProcessW` с `CREATE_NO_WINDOW |
  CREATE_SUSPENDED` и списком наследуемых хэндлов `PROC_THREAD_ATTRIBUTE_HANDLE_LIST`,
  чтобы пайпы не утекали в другие процессы. Процесс помещается в **Job Object** с
  `KILL_ON_JOB_CLOSE` и `DIE_ON_UNHANDLED_EXCEPTION`: убивается всё дерево, а при
  падении программы не всплывает окно «прекращена работа». Два фоновых потока
  читают пайпы, главный цикл раз в ~15 мс забирает данные из очереди под `SRWLOCK`.
  Все хэндлы обёрнуты в RAII (`util::Handle`), потоки корректно дожидаются
  (с `CancelSynchronousIo` как страховкой).
* **Ошибки компилятора.** Разбираются форматы GCC/Clang (`main.cpp:12:5: error:`)
  и MSVC (`main.cpp(12,5): error C2065:`). Ошибки выводятся красным,
  предупреждения жёлтым, заметки голубым. Строки с ошибками отмечаются `►` в
  колонке номеров, курсор прыгает к первой ошибке. Код выхода программы
  расшифровывается (`0xC0000005 — ACCESS_VIOLATION` и т.д.).
* **Кодировки.** Внутри всё в UTF-16. Вывод программы декодируется как UTF-8
  (с откатом на OEM-кодировку), многобайтовые символы на границе чанков не
  рвутся. Для MSVC задаётся `VSLANG=1033`, чтобы сообщения были на английском.

## Тесты

Самопроверка не-UI частей: Runner (вывод, stdin, stderr, kill, коды падения),
парсер ошибок GCC/MSVC, редактор (автоотступ, undo/redo, склейка строк),
панель вывода (`\r`, ANSI, перенос) и UTF-8-декодер.

```bat
g++ -std=c++17 -O2 -static -o child.exe tests\child.cpp
g++ -std=c++17 -O2 -static -o selftest.exe tests\selftest.cpp src\Common.cpp src\Runner.cpp src\Compiler.cpp src\Editor.cpp src\OutputPane.cpp src\Syntax.cpp src\Console.cpp -lshell32
selftest.exe child.exe
```

## Ограничения

* Нужна Windows 10 1607+ (VT-режим консоли). Лучше всего выглядит в Windows Terminal.
* Мышь используется для прокрутки, поэтому в классическом conhost отключён режим
  QuickEdit: выделять текст мышью там нельзя. В Windows Terminal выделение работает
  с зажатым Shift.
* Программа видит пайпы, а не консоль: функции вроде `system("cls")`, `getch()`
  или цветной вывод через `SetConsoleTextAttribute` не работают. ANSI-коды цвета
  из вывода вырезаются.
* Ширина символов считается равной 1 (CJK и эмодзи могут сдвигать строку).
* Таймаут считает реальное время, включая ожидание ввода.

## Идеи для улучшения

1. **Автодополнение** в редакторе: ключевые слова, идентификаторы из текущего файла,
   члены `std::` по встроенному словарю; со временем — через `clangd` по протоколу LSP.
2. **Вкладки**: несколько файлов, переключение Ctrl+Tab, многофайловые проекты.
3. **Выделение текста** (Shift+стрелки), копирование и вырезание, поиск и замена (Ctrl+F / Ctrl+H).
4. **ConPTY** (`CreatePseudoConsole`): программа получит настоящую консоль, заработают
   цвета, `getch()` и `system("cls")`.
5. **Ошибки прямо в коде**: подчёркивание места ошибки по колонке и текст в строке состояния.
6. **Больше тем** и загрузка пользовательских тем из `.ini`, настройка шрифта и
   соотношения панелей редактора и вывода.
7. **Флаги компиляции** (`:flags -O0 -g -fsanitize=address`), профили Debug/Release,
   передача аргументов командной строки (`:args`).
8. **Отладка**: интеграция с `gdb --interpreter=mi` и точки останова в колонке номеров.
9. **Сниппеты** (`for`, `class`, `main`) и подсветка парных скобок.
10. **Сравнение вывода** с эталонным файлом, как в олимпиадных тестерах: `:test in.txt out.txt`.
11. **Звуковые эффекты** набора текста и «взлома» через `PlaySound`.
