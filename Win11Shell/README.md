# Win11Shell — копия интерфейса Windows 11 на C++17

Одно нативное приложение Windows, которое воспроизводит интерфейс Windows 11: рабочий стол, панель задач,
меню «Пуск», центр уведомлений, быстрые параметры, виджеты и набор приложений. Всё рисуется вручную
в одном полноэкранном окне `WS_POPUP` с двойной буферизацией (DIB-секция в памяти + `BitBlt`), а все
«окна» внутри — собственные объекты, которыми управляет собственный оконный менеджер.

Используются только WinAPI и встроенные компоненты Windows: GDI+, DWM, WinMM (звук). Сторонних
библиотек, NuGet-пакетов, Qt, SDL или ImGui нет. Значки, обои, карта мира и звуки созданы программно;
логотипы и изображения Microsoft не используются.

## Сборка

1. Откройте `Win11Shell.sln` в Visual Studio 2022 (набор инструментов v143, компонент «Разработка
   классических приложений на C++», Windows SDK 10).
2. Выберите конфигурацию `Release | x64` (или `Debug | x64`).
3. Соберите решение (`Ctrl+Shift+B`) и запустите (`Ctrl+F5`).

Параметры проекта: платформа x64, набор символов Unicode, стандарт C++17 (`/std:c++17`), уровень
предупреждений `/W4`, `/utf-8`, `/permissive-`, SDL-проверки, подсистема Windows. Исходники в UTF-8 с BOM.
Подключаемые библиотеки: `gdiplus.lib`, `dwmapi.lib`, `winmm.lib`, `user32.lib`, `gdi32.lib`,
`advapi32.lib`, `ole32.lib`, `shell32.lib`.

Готовый файл: `bin\x64\Release\Win11Shell.exe`.

## Выход из программы

Оболочка занимает весь экран и перехватывает клавишу Win. Чтобы выйти, откройте **Пуск → Питание →
Завершение работы** или нажмите **Alt+F4** на рабочем столе (когда нет активного окна) и выберите
«Завершение работы».

## Что реализовано

**Оболочка**
- Рабочий стол с ярлыками (перетаскивание, выделение рамкой, переименование, контекстные меню,
  «Показать дополнительные параметры»), собственные градиентные обои.
- Панель задач: Пуск, поиск, представление задач, закреплённые и запущенные приложения с превью,
  виджеты с текущей погодой, область уведомлений, часы.
- Меню «Пуск» с поиском по приложениям (в том числе по английским словам), параметрам и файлам,
  закреплёнными и рекомендуемыми элементами, меню питания.
- Центр уведомлений с календарём и сеансом фокусировки, быстрые параметры (Wi-Fi, Bluetooth, режим
  «в самолёте», ночной свет, яркость, громкость), всплывающие уведомления, виджеты, Win+X-меню,
  представление задач, экраны блокировки и завершения работы.
- Оконный менеджер: перетаскивание, изменение размера, свернуть/развернуть/закрыть с анимациями,
  привязка к краям и макеты прикрепления, Alt+Tab, порядок по Z, диалоги внутри окон.
- Светлая и тёмная темы с мгновенным переключением, цвет акцента, имитация Mica и Acrylic, мягкие
  тени, скругление углов 8 px, сглаживание GDI+ и ClearType, шрифт Segoe UI, поддержка DPI.
- Виртуальная файловая система: «Этот компьютер», диски, папки пользователя, корзина.

**Приложения**
- **Проводник** — вкладки, навигация, «хлебные крошки», поиск, представления, область сведений,
  перетаскивание, копирование и перемещение, корзина, свойства.
- **Блокнот** — вкладки, правка, поиск и замена, переход к строке, сохранение в ФС.
- **Параметры** — разделы системы, персонализации, сети, приложений, учётных записей и др.;
  изменения темы, акцента, обоев и прозрачности применяются сразу.
- **Калькулятор** — обычный, инженерный, конвертеры величин, журнал и память.
- **Терминал** — PowerShell и командная строка с командами для виртуальной ФС.
- **Диспетчер задач** — процессы, производительность (реальные ЦП и память), автозагрузка, службы.
- **Paint** — инструменты, кисти, фигуры, палитра и выбор цвета, выделение, буфер обмена
  (вставка снимков экрана), отмена и повтор, масштаб, сохранение.
- **Фотографии** — галерея и просмотр.
- **Часы** — фокусировка, таймеры, будильники, секундомер, мировое время с картой дня и ночи.
- **Погода** — прогноз, график по часам, подробности, карта температуры, климат, избранное.
- **Браузер** — вкладки, история, избранное, поиск и встроенные страницы (без сети).
- **Медиаплеер** — библиотека музыки и видео, очередь, режим «Сейчас воспроизводится»;
  музыка синтезируется в реальном времени и выводится через waveOut.
- **Календарь** — день, неделя, месяц, праздники России, создание и изменение событий.
- **Почта**, **Магазин**, **Камера**, **Карты**, **Советы** — упрощённые, но рабочие приложения.

## Сочетания клавиш

| Клавиши | Действие |
|---|---|
| Win | Меню «Пуск» |
| Win + E / Win + I | Проводник / Параметры |
| Win + A / Win + N / Win + W | Быстрые параметры / уведомления / виджеты |
| Win + D / Win + M | Показать рабочий стол / свернуть все |
| Win + Tab, Alt + Tab | Представление задач, переключение окон |
| Win + стрелки | Привязка окна |
| Win + X / Win + L / Win + R | Меню ссылок / блокировка / Терминал |
| PrtScn | Снимок экрана (в буфер и в «Изображения\Снимки экрана») |
| Ctrl + Shift + Esc | Диспетчер задач |
| Alt + F4 | Закрыть окно; на рабочем столе — завершение работы |

## Структура исходников

```
src/
  main.cpp               WinMain, оконная процедура, перехват Win, таймеры
  Common.h/.cpp          геометрия, цвет, время, анимации, строки
  Theme.h                палитры светлой и тёмной темы, акцент
  Renderer.h/.cpp        отрисовка (GDI+ на DIB), тени, Acrylic/Mica, текст
  Icons.h/.cpp           значки и значки приложений, нарисованные кодом
  Widget.h, Controls.*   элементы управления (кнопки, поля, переключатели, списки)
  WindowManager.*        окна, привязка, анимации, диалоги
  Desktop.*, Taskbar.*, StartMenu.*, Flyouts.*, Overlays.*, ContextMenu.*
  Shell.*                связка оболочки и запуск приложений
  VirtualFS.*            виртуальная файловая система
  Apps.*                 реестр приложений
  apps/                  приложения и общие модули (ImmUi, TabStrip, WorldMap, Cities, WeatherData…)
```
