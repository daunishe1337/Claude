# ЗАДНЕЕ СИДЕНЬЕ

Небольшая хоррор-игра на C++17 по мотивам механик *The Deadseat* (Curious Fox Sox).
Все ассеты, тексты и звуки оригинальные и создаются кодом.

Ночь, длинная дорога домой. Ты ребёнок на заднем сиденье. Родители ругаются впереди и не
замечают, что на крышу машины забралось *нечто*. У тебя есть портативная консоль GAMEKID,
и предметы, собранные в её мини-игре «FUEL RUN», работают в реальном мире.

* Только стандартная библиотека C++17 и WinAPI: окно, GDI (`StretchDIBits`), `waveOut`.
  Никаких SDL/SFML/OpenGL/stb, никаких внешних файлов.
* Программный рендер в буфер `uint32_t` 320×180, вывод с целочисленным масштабированием.
* Весь звук процедурный: гул двигателя, шум дороги, дождь, сердцебиение, писк консоли,
  чиптюн-мелодия, шаги и скрежет по крыше, стук по стеклу, «бубнёж» родителей.
* Фиксированный шаг логики 60 Гц.

## Сборка в Visual Studio

1. Установите Visual Studio 2019 или 2022 с рабочей нагрузкой
   **«Разработка классических приложений на C++»** (Desktop development with C++).
2. Откройте `BackSeat/BackSeat.sln`.
3. Нажмите **F5** (или Ctrl+F5). Конфигурация по умолчанию `Debug | x64`; для
   максимальной производительности выберите `Release`.

Проект уже настроен: подсистема Windows, C++17, `/utf-8`, ссылки на `winmm.lib`,
`user32.lib`, `gdi32.lib`. Набор инструментов берётся из установленной версии Visual Studio
(`$(DefaultPlatformToolset)`), поэтому перенастраивать проект не нужно. Исполняемый файл
попадает в `BackSeat/bin/<платформа>/<конфигурация>/`.

Если вы создаёте проект вручную: добавьте все файлы из `src/`, выберите стандарт C++17,
добавьте ключ `/utf-8`. Библиотеки подключаются через `#pragma comment(lib, ...)`.
Точек входа две (`WinMain` и `main`), поэтому игра запустится и при консольной подсистеме.

## Управление

| Клавиша | Действие |
|---|---|
| `TAB` / `ПРОБЕЛ` / ПКМ | поднять/опустить консоль (переключить вид) |
| `A`/`D` или `←`/`→` | в консоли: руль машинки |
| `A` / `W` / `D` / `S` (или стрелки), мышь | в реальном мире: навести камеру на левое окно / люк / правое окно / вперёд |
| `F` / ЛКМ | сделать снимок со вспышкой |
| `ESC` | пауза (в меню — выход) |
| `R` | начать заново (пауза, проигрыш, победа) |
| `Q` | из паузы в меню |
| `M` | выключить/включить звук |
| `E` | громкость +10% (после 100% — снова 10%) |
| `F11` / `Alt+Enter` | полноэкранный режим |
| `ENTER` | начать игру |
| `←`/`→` (в меню) | выбор сложности |
| `TAB` (в меню) | список достижений |
| `INS` | админ-панель (пароль 1667) |

## Сложность

Выбирается в меню стрелками `←`/`→` и показывается на экране итогов.

| Параметр | Лёгкая | Нормальная | Сложная |
|---|---|---|---|
| Расход бензина, ед./с | 1.1 | 1.5 | 2.0 |
| Канистра | +28 | +22 | +10 |
| Первый визит монстра | 35 с | 22 с | 5 с |
| Скорость взлома | ×0.7 | ×1.0 | ×2.0 |
| Перезарядка вспышки | 3 с | 4 с | 4 с |

## Достижения

40 достижений (часть — секретные), список открывается в меню клавишей `TAB`. Прогресс сохраняется в файл
`backseat_save.txt` рядом с `.exe`; если записать туда нельзя, достижения живут до выхода.

## Секрет: бесконечная дорога

В главном меню нажмите `F` пять раз за две секунды (повтор — выключить). Дом не
приближается, считаются километры, а родители всё чаще замечают, что дорога «повторяется».
Через 3 минуты они замолкают и оборачиваются... Удерживайте `F`, чтобы притвориться
спящим: держите бегунок дыхания клавишами `A`/`D` в зелёной зоне. Короткое нажатие `F`
по-прежнему делает снимок.

Стоит закрыть глаза, как родители становятся странными: обычная ссора обрывается, и
звучат разговоры, которые не предназначены для ребёнка (субтитры видны и с закрытыми
глазами). Открыв глаза, можно на миг застать их обернувшимися. Пока дыхание ровное,
гость не прилетает на крышу, а если уже там — уходит. После того как родители
обернулись, «спящему» они шепчут.

## Админ-панель

`INS` в любой момент открывает админ-панель (пароль `1667`, `Backspace` стирает).
Пока она открыта, игра стоит. Внутри: автосон (сам держит дыхание), бессмертие,
бесконечный бензин, автопилот мини-игры, всегда заряженная камера, авто-победа,
«прогнать гостя», «сразу к безликим», переключение бесконечной дороги и открытие всех
достижений. Пока включён хоть один чит, внизу экрана горит `ADMIN`.

## Как играть

* **Бензин** постоянно убывает. Пополнить его можно только канистрами из мини-игры на
  консоли. Если бак опустеет, двигатель чихает несколько секунд (ещё можно успеть подобрать
  канистру), а потом глохнет. Это проигрыш.
* **Монстр** прыгает на крышу (слышен удар, сыплется пыль), ползёт по ней (шаги и скрежет
  слышны слева или справа), затем появляется в одном из окон: левом, правом или в люке.
  После этого он начинает ломиться внутрь, и шкала угрозы растёт. Когда она заполнится,
  он доберётся до тебя.
* **Камера** (её нужно найти в мини-игре): наведи видоискатель на окно с монстром и сделай
  снимок. Вспышка отпугнёт его. После снимка вспышке нужно время на перезарядку.
* **Батарейка** мгновенно заряжает вспышку и делает следующую вспышку усиленной.
  **Замок** на время блокирует окна: монстр ломится медленнее, угроза снижается.
* Мини-игра **не встаёт на паузу**, пока ты смотришь в окно. Машинка едет сама и может
  разбиться, а громкий писк консоли привлекает монстра.
* Доберись до дома: шкала пути в правом верхнем углу.

## Архитектура

```
src/
  main.cpp            точка входа WinMain, цикл с фиксированным шагом 60 Гц
  Platform.h/.cpp     окно WinAPI, сообщения, вывод кадра через StretchDIBits, полный экран
  Input.h/.cpp        клавиатура/мышь, защёлкивание нажатий для фиксированного шага
  Renderer.h/.cpp     Canvas: программный растеризатор (примитивы, полигоны, трафарет, эффекты)
  Font.h/.cpp         встроенный растровый шрифт 5×7 (латиница + кириллица, UTF-8)
  Hud.h/.cpp          шкалы, значки, подсказки, субтитры
  Audio.h/.cpp        вывод звука через waveOut в отдельном потоке
  Synth.h/.cpp        процедурный синтезатор и микшер: эффекты и непрерывные слои
  ConsoleMiniGame.*   мини-игра «FUEL RUN» (4 оттенка) и отрисовка самой консоли
  Monster.h/.cpp      конечный автомат монстра, угроза, агрессия
  Parents.h/.cpp      ссора родителей, реплики-реакции, субтитры
  RealWorldScene.*    вид с заднего сиденья: салон, окна, пейзаж, фонари, монстр, HUD
  Game.h/.cpp         главный конечный автомат: меню, поездка, пауза, проигрыш, победа
```

Модули общаются через узкие интерфейсы. `Monster`, `ConsoleMiniGame` и `Parents` ничего
не рисуют и не играют звуков: они выдают события, а `Game` превращает их в звук, картинку
и последствия. Всё, кроме `Platform`, `Audio.cpp` и `main.cpp`, не зависит от WinAPI.
